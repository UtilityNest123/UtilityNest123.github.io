# UtilityNest — Centralized Web Tools, Calculators & Market Hub

**Live Website:** [https://utilitynest123.github.io/](https://utilitynest123.github.io/)

UtilityNest is a privacy-first digital utility network that brings together fast, browser-based tools, engineering and financial simulators, productivity generators, and automated daily market price tracking in one unified hub.

## Connected Platforms

1. **[UtilityNest WebToolBox](https://utilitynest123.github.io/WebToolBox/)** — Client-side image resizer, JPG/PNG to PDF converter, real-time currency converter, and stylish Unicode font generator.
2. **[Calcvora](https://utilitynest123.github.io/calcvora/)** — Precision simulators including Local LLM VRAM & API Cost Calculator, Off-Grid Solar Battery Sizing, and Global Freelance Net-Income Calculator.
3. **[ZeptoSolve](https://utilitynest123.github.io/zeptosolve/)** — Productivity and wellness utilities featuring Notion Formula 2.0 Generator, Bangladesh Income Tax Calculator, and Digital Detox guides.
4. **[DD Bazar](https://utilitynest123.github.io/ddbazar/)** — Automated daily retail and wholesale commodity price tracker covering all 8 administrative divisions of Bangladesh.

## Key Highlights

- **100% Client-Side Privacy:** File conversions and calculations run locally inside your browser without uploading data to external servers.
- **Responsive Design:** Optimized for mobile phones, tablets, laptops, and desktop displays with Bright and Dark mode support.
- **Free Access:** No registration, login, or subscription required.
